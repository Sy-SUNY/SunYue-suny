AGENT DEVELOPMENT / 运维自动化与测试

海洋牧场运维 Agent

自研告警工作流，连接日志分析、业务查询、定向测试和错误报告。

项目负责人 · 需求调研、技术链路设计、Agent 开发与系统验证

项目要解决的问题

海洋牧场的运维分析既需要设备与采集服务的日志，也需要水温等业务数据。单独看到一条告警，很难直接判断异常发生在哪里、需要补查什么，以及该如何验证。

本项目将这些线索组织到统一的 Agent 工作流中，让告警进入后可以继续检索资料、查询数据、触发针对性检查，并输出带有依据和验证结果的错误报告。

自研告警处置工作流

告警接入 → 日志与文档检索 → Skill 调用 → 定向测试 → 错误报告 → 企业微信通知

基于 LangGraph 编排模型、工具和知识检索节点，将日志分析、资料检索、业务数据查询、测试验证和报告生成连接起来，记录处理过程与执行结果。

开发与交付

日志与运维文档接入：接入运行日志和运维资料，围绕告警对象检索相关记录与处理依据，为异常分析提供上下文。

业务 Skill 封装：将水温等业务数据查询与相关检查流程封装为可调用能力，由 Agent 根据问题选择执行，并将查询结果带回分析流程。

定向测试与错误报告：根据告警对象及异常线索组织针对性验证，将问题现象、日志证据、测试过程、执行结果和后续检查建议整理为错误报告。

企业微信集成：接入企业微信，发送告警与错误报告，让运维分析和验证结果进入团队的工作沟通渠道。

迭代方向与交付

从环境查询、设备诊断与知识检索能力出发，扩展为包含告警接入、Skill 调用、定向测试、报告生成和通知反馈的运维工作流。

交付内容：运维告警工作流、日志与文档接入、业务查询 Skill、定向测试流程、错误报告生成能力与企业微信通知集成。
